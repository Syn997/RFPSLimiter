# C++ RFPSLimiter

Simple C++ App to activate / deactivate the FPS Limiter in RivaStatisticsTuner

## Features

- Press Shift F1 to enable the FPS Limiter in Riva Statistics Tuner
- Press Shift F2 to disable the FPS Limiter in Riva Statistics Tuner
- Press Shift F3 to disable the Limiter and exit the Application

## Requirements

- Windows
- Microsoft Visual C++ compiler (`cl.exe`)
- Windows SDK
- RTSS-CLI placed under /tools to run


This is a learning project, so things might be a little rough around the edges. That's part of the fun.
